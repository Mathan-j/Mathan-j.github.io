Flagship

clause

A regulatory answer engine over 61 RBI circulars where every factual sentence resolves to an exact character range in an exact document — not "source: circular.pdf", but characters 1,769 to 3,741 of that specific direction, highlighted in the stored text.

The model never writes a citation. It sees numbered passages and can only reference them by index, and a GBNF grammar constrains decoding so an out-of-range index cannot be generated. The resolver slices the text from the corpus itself. An answer whose citation fails to resolve is discarded rather than returned.

Measured limitation

At the default threshold the refusal gate caught 0 of 15 deliberately unanswerable questions, while turning away 5 answerable ones. A retrieval score does not separate answerable from unanswerable — there is no setting that keeps the good questions and blocks the bad. Published rather than hidden.

How I work

From idea to production

The order matters. Evaluation before agents, guardrails before deployment — skip a stage and you ship something you cannot debug later.

01

Architecture

Design the LLM and agent system, and decide what is configuration.

02

Retrieval

Build and tune the pipeline: chunking, embeddings, vector store.

03

Evaluation

Score it against a real corpus. Report per bucket, not one average.

04

Agents

Orchestrate workflows and tool use with checkpoints on costly actions.

05

Guardrails

Enforcement hooks, review agents, injection corpus in CI.

06

Deployment

Ship and operate inside the client environment, with observability.
